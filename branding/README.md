# Branding

Drop the official Atomic Knockout cover art here.

Expected files (regenerated by `npm run branding:icons` from `cover.jpg` or `cover.png`):

| File | Purpose |
|---|---|
| `cover.jpg` / `cover.png` | Full square cover / store art |
| `icon.ico` | Windows desktop + installer icon |
| `icon.png` | 128×128 fallback |
| `icon-256.png` | High-res PNG icon |
| `icon-512.png` | Store / Netlify hero thumb |

When you replace the cover, run:

```bash
npm run branding:icons
```
