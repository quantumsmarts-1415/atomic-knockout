# Smash Ring stage music (Hydra, v2 set)

All tracks are seamless loops (reverb tails folded onto the start): same melody, harmony, key, tempo and length as the first set, re-orchestrated in style D (rock kit + taiko, guitars + staccato cellos, brass + guitar melody, choir/brass hits, string swells). Mastered to -19 LUFS integrated, TP ceiling -2 dBTP; values below are measured on the ENCODED files (ffmpeg ebur128, true peak). Prefer OGG for looping (MP3 adds ~40 ms encoder padding). A clash-cleanup pass moved harmony doubles (and, in brimstone-caldera, a few lead notes) onto chord tones in every stage track; the edit list is in the music_v2 fixes changelog.
